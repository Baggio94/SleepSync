# Contributing

Bug reports and focused pull requests are welcome.

When reporting a bug, please include:

- Android version;
- device model;
- Syncthing-Fork version;
- whether **Settings → Behaviour → Service Control by Broadcast** is enabled;
- the **Last activity** shown by SleepSync;
- exact steps to reproduce the problem.

Please avoid including Syncthing device IDs, private folder names, addresses, or other personal information in issue reports.
